  ü: search in file forward

  \C in search to only search lowercase instead of mixed,

  space sg/G: search in root directory / workspace directory
    executes grep
    not fuzzy search input
    alt+t / ctrl+q works in this picker
  space + cr: rename all references
  :s/pattern/replacement: replace in line
  :,pattern/s/match/replacement: substitute from current line
    instead of just first occurrence on a line
  :%s/term/replacement substitution in entire file
    % is a range and stands for the whole file
    append / or separator g to replace all instances of a word
    append /gc to add confirmations
    append /I to enforce case
    instead of just first occurrence on a line
    %sg repeat last search and replace in the whole file 
  visual selection and :s visual selection is automatically inserted 
  range can be added at the beginning of a command in the format start,end separator s separator 
  :%sg: repeat substitution
  space sr: replace in all files 
    commit before use
    files filter accepts globbing

  :<range>,norm: execute a number of commands on range

4. The "Macro" Approach
If you have 10–20 instances and want total control:

Search for the function: /myFunction(.

Start recording a macro: qq.

Find the closing parenthesis: f).

Insert the argument: i, new_arg<Esc>.

Move to the next occurrence: n.

Stop recording: q.

Play it back until done: 99@q.
