# Instructions
- Create a /docs folder, /docs/work_packages/specs, /docs/work_packages/bugs, /logs/implementation and /logs/testing folders.
- In the root directory create an Agents.md file with the following template structure:

Agents.md Template:
    1. Project overview
        1.1 Goals
        1.2 Technology
        1.3 Glossary and Definitions
        1.4 UI
        1.5 API
        1.6 Database
        1.7 Docs
    2. Build commands
    3. Run commands
        3.1 As User
        3.2 As Agent
    4. Code style guidelines
    5. Testing instructions
    6. Security considerations
    7. Deployment

- Ask the user for the goals and technology and write them to the Agents.md in the right place under 1.
