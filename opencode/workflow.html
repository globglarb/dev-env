Agent Workflow

User → Work Package → Architect → Engineer → Tester

👤 User
flowchart TD
    A["Submits work package,<br>bug, or document"]
    B["Reviews proposals<br>& provides feedback"]
    C{"Approves?"}
    D["Grants permission<br>to proceed"]
    A-->B-->C
    C-. No .->B
    C-- Yes -->D
📦 Work Package
flowchart TD
    A["Feature specification<br>document"]
    B["Broken into tasks<br>for implementation"]
    A-->B
🧠 Software Architect
flowchart TD
    A["Receive work pkg,<br>bug, or document"]
    B["Ignore docs/logs<br>during analysis"]
    C["Design spec &<br>implementation plan"]
    D["Break down by:<br>API / DB Schema /<br>Service / Component"]
    E["Present each change<br>to user for review"]
    F{"Approved?"}
    G["Break into parallel<br>tasks for Engineer"]
    H["Include test scope,<br>not full test code"]
    I["Use instruction<br>template for agent"]
    J["Save tasks to<br>/docs/logs/implementation"]
    K{"Permission to<br>start?"}
    L["Send tasks in order<br>to Engineer agent"]
    M["Check responses;<br>report issues to user"]
    A-->B-->C-->D-->E-->F
    F-. No .->E
    F-- Yes -->G-->H-->I-->J-->K
    K-- Yes -->L-->M
👨‍💻 Software Engineer
flowchart TD
    A["Read specification<br>carefully"]
    B{"Ambiguous?"}
    C["Ask for<br>clarification"]
    D["Implement per spec"]
    E["Add missing test<br>infra / packages"]
    F["Design tests:<br>Unit / API / Integration"]
    G["Mirror src tree<br>in /tests folder"]
    H["Test with real values,<br>faulty data, edge cases"]
    I["Run all tests"]
    J{"All pass?"}
    K["Implementation<br>complete"]
    A-->B
    B-. Yes .->C
    C-.->A
    B-- No -->D-->E-->F-->G-->H-->I-->J
    J-. No .->D
    J-- Yes -->K
🧠 Software Architect (Post)
flowchart TD
    A["Engineer impl.<br>complete"]

    A-->B-->C-->D
    D-- Yes -->E-->F-->G
🧪 Software Tester
flowchart TD
    A["Receive testing scope<br>& context"]
    B["Check existing tests;<br>run & review failures"]
    C{"Has UI?"}
    D["Navigate UI in browser;<br>do NOT read code"]
    E["Read code if needed<br>for test design"]
    F["Design e2e tests:<br>single actions & sequences"]
    G["Test happy path,<br>bad input, edge cases"]
    H["Run all tests"]
    I{"All pass?"}
    J["Review: requirements<br>change or regression?"]
    K{"Genuine bug?"}
    L["Create bug doc in<br>/docs/work_packages/bugs"]
    M["Save summary to<br>/docs/logs/testing"]
    N["Update Agents.md<br>testing instructions"]
    A-->B-->C
    C-- Yes -->D-->F
    C-- No -->E-->F
    F-->G-->H-->I
    I-- Yes -->M
    I-. No .->J
    J-->K
    K-- Yes -->L-->M
    K-. No .->H
    M-->N
