# Plugins
flash.nvim - seek mode
  s - enter seek mode
  operator pending mode + S - enter seek mode in operation

which-key plugin
  any character + wait time - pops up space menu for this key
  space - open top level keys

nvim-spider
  use web commands on snake and camelcase etc.

snacks.nvim
  file picker and many other small plugins

bufferline.nvim
  shows open buffers

yanky.nvim
  picker for text in clipboard

mason.nvim
  package manager for coding

Noice
  for notification pop ups

Trouble
  enhanced quickfix

conform.nvim
  formatting plugin

nvim-treesitter-context
  pin context to top line for large objects

Grug-far.nvim
  search and replace for files

blink.cmp
  shows hint and autocompletions

nvim-snippets
  snippet support, comes with pre-defined snippets

text-case.nvim
  change word formatting, specifically coding like camel case

editor.dial
  increment many objects, like true false, dates, etc.

dap.core
  plugin for debug adapter protocol, base for language debug packages

test.core
  neotest, plugin for test management and test execution

# Interesting Plugins
undotree - visualized neovim undo operations and navigate branches

nvim-rip-substitute
  search and replace with grep and regular expressions

chrome-debug-adapter
  connect to chrome debugger to set frontend breakpoints and debug 
  in neovim

# Management
:LazyExtras - LazyVim extras
  x - install extra
  provides language extras 
  documentation - https://www.lazyvim.org/extras

space + fc - show all configuration files
LazyVim loads all files from lua/plugins folder
